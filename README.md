# Personal Site
 
Source for my personal site and project archive, hosted on GitHub Pages.
 
🌐 **Live:** [srihitaramanan.github.io](https://srihitaramanan.github.io)
 
## About
 
A portfolio where I add details of my projects as I build them.
 
## Stack
 
- HTML5 + CSS (no JS framework)
- Fonts: Fraunces, JetBrains Mono (Google Fonts)
- Hosted on GitHub Pages
## Local Preview
 
Clone and open `index.html` in a browser, or serve it with anything that talks HTTP:
 
```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```
